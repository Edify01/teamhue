Install TeamHue

TeamHue isn't on the Chrome Web Store yet, so it installs as an unpacked extension — exactly how Chrome is designed to run developer extensions.

Download TeamHue

Chrome, Edge, Brave or Arc · Version 1.0.0

  1. Unzip the download. You'll get a folder called teamhue. Keep it somewhere permanent — Chrome loads it from this location every time it starts.
  2. Open your extensions page. Paste chrome://extensions into your address bar and press Enter.
  3. Turn on Developer mode using the toggle in the top-right corner.
  4. Click "Load unpacked" and select the teamhue folder you unzipped.
  5. Pin it. Click the puzzle-piece icon in your toolbar and pin TeamHue for quick access. The setup page opens automatically.
Everyone on your team repeats these steps on their own computer. Then one person creates the team and shares the join code — that's what makes the colors match everywhere.

Questions

How do teammates see the same colors on different computers?

Everyone signs into a shared TeamHue account — which is separate from your Google or Chrome profile. One person creates a team and gets a join code like BRIGHT-OTTER-42. Anyone who enters that code joins the same workspace and sees identical colors, no matter whose computer they're on or which Google account Chrome is signed into.

Does TeamHue read my messages?

No. TeamHue stores only a conversation identifier (a thread ID, phone number, or email address), a color, and optionally a name and short note. Message content is never read, stored or transmitted.

Where is my data stored?

In your own Supabase database. There's no TeamHue server in the middle — your team's data goes directly from your browser to infrastructure you control.

Why isn't this on the Chrome Web Store?

Store review takes a few weeks for extensions that request access to sites like Gmail. Loading it unpacked works identically and lets you start today. A Web Store listing is planned.

Will it break when Instagram or Gmail update their design?

TeamHue deliberately avoids the fragile parts of those pages. Instead of CSS class names (which change often), it anchors on stable things like the thread ID in the URL and the sender's email address. If a site does change in a way that affects it, the fix is small and the extension never breaks the page itself.

Does everyone need to use the same colors?

The color assigned to each conversation is shared. How it's displayed — tint strength, accent bars, initials badges, which sites it runs on — is a personal setting that only affects you.

How much does it cost?

TeamHue is free and open source. Supabase's free tier comfortably covers a team of this kind, so most teams pay nothing at all.
